Озвучка сообщений чата Twitch голосом: каждое сообщение зачитывается вслух на стриме.
Продолжение [[obs_twitch_chat]] — работает внутри того же виджета, плюс локальный сервер
синтеза речи. Сделана 28.09.2026. Ник автора не читается, только текст.

## Перед стримом

Сервер озвучки запускается вручную — автозапуск выключен, чтобы он не висел в памяти,
когда стрима нет:

```
systemctl --user start chat-tts
```

Модель грузится пару секунд. OBS можно открывать до или после — порядок не важен.

После стрима:

```
systemctl --user stop chat-tts
```

Пока сервер выключен, сообщения просто не озвучиваются, ошибок в OBS нет. Пропущенные
сообщения потом не зачитываются.

## Во время стрима

- **Громкость** — ползунок «Audio · Озвучка чата» в микшере OBS.
- **Выключить на время** — значок динамика у того же источника.
- **Голос пропал** — проверить `systemctl --user status chat-tts`, перезапустить
  `systemctl --user restart chat-tts`.

## Что зачитывается

Пропускаются:

- команды (`!discord` и т.п.);
- боты: Nightbot, StreamElements, Moobot и все ники на `…bot`;
- собственные сообщения стримера;
- сообщения, удаленные модератором или после бана, — в том числе уже стоящие в очереди;
- сообщения из одних эмоутов, эмодзи или символов.

Текст перед синтезом приводится к читаемому виду:

- ссылки → «ссылка», `@ник` → просто ник;
- числа словами: «25 побед» → «двадцать пять побед», «100%» → «сто процентов»;
  числа длиннее 6 цифр (коды, id) пропускаются;
- сленг по словарю: gg → «гэгэ», lol → «лол», xd → «иксдэ», ez → «изи»;
- остальная латиница транслитерируется: «Black Myth Wukong» → «блак мит вуконг»;
- «ааааааа» и «!!!!!!» сокращаются до трех символов, длинные сообщения обрезаются
  до 200 символов.

Сообщения читаются строго по очереди. Очередь не больше 8 сообщений: при спаме старые
выбрасываются, чтобы озвучка не отставала от чата на минуты.

## Как устроено

| Часть | Где |
| --- | --- |
| Сервер синтеза | `~/develop/obs-twitch-chat/tts/server.py`, порт `127.0.0.1:47815` |
| Нормализация текста | `~/develop/obs-twitch-chat/tts/normalize.py` |
| systemd-сервис | `~/.config/systemd/user/chat-tts.service` |
| Модель | Silero `v5_5_ru`, голос `baya`, `tts/voices/silero_v5_5_ru.pt` |
| Python-окружение | `tts/.venv-silero-cpu` (PyTorch, CPU-сборка) |
| Источник в OBS | «Audio · Озвучка чата», есть во всех сценах |

Источник — отдельный браузер-источник с тем же `chat.html`, но с `tts=true`:

```
file:///home/kkulebaev/develop/obs-twitch-chat/chat.html?channel=tinkerdev&bot_activity=true&tts=true
```

Сам чат в нем скрыт CSS (`#chat_box { display: none; }`), включено «Управлять звуком
через OBS», прослушивание — «Прослушивание и вывод», как у музыки. Отдельный источник
нужен потому, что три видимых чата стоят в разных сценах, а OBS выводит звук только
из активной — озвучка пропадала бы при смене сцены. По той же причине `tts=true` нельзя
ставить видимым чатам: каждое сообщение прозвучало бы несколько раз.

Параметры URL виджета: `tts_speed`, `tts_volume` (0–1), `tts_max` (длина в символах),
`tts_self=true` — зачитывать и сообщения стримера.

## Настройки голоса

Задаются переменными окружения в `chat-tts.service` (строка `Environment=`), после правки —
`systemctl --user daemon-reload && systemctl --user restart chat-tts`.

| Переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `TTS_VOICE` | `baya` | голос; женские `xenia`, `baya`, `kseniya`, мужские `aidar`, `eugene` |
| `TTS_BASE_SPEED` | `0.8` | темп; у Silero он только ступенчатый: `<0.7` — очень медленно, `<0.9` — медленно, `1` — естественный |
| `TTS_LEAD_SILENCE` | `0.35` | тишина перед фразой, секунды |
| `TTS_ENGINE` | `silero` | `piper` — запасной движок (см. ниже) |

Естественный темп `baya` оказался быстроват — стоит «медленно».

## Грабли

- **Начало фразы съедалось.** OBS заново открывал аудиопоток браузер-источника на каждой
  фразе и отрезал первые слоги; тишина в самом WAV не помогала. Поэтому звук идет через
  постоянно работающий Web Audio с неслышимым тоном −100 дБ — поток не закрывается.
- **Silero знает только кириллицу.** Цифры и латиницу выбрасывает молча, а на сообщении
  без единой русской буквы («gg wp») падал с ошибкой — отсюда `normalize.py`.
- **PyTorch ставить только из CPU-индекса**, без дополнительного PyPI-индекса — иначе
  `uv` тянет CUDA-сборку на 5 ГБ, бесполезную на AMD:

  ```
  uv pip install --python .venv-silero-cpu --index-url https://download.pytorch.org/whl/cpu torch numpy
  ```

- **Лицензия** моделей Silero — CC BY-NC, только некоммерческое использование.

## Откат на Piper

Первая версия работала на Piper (голос `irina`) — звучит роботизированнее и путает
ударения, но легкий. Он остался в `tts/.venv`: в `chat-tts.service` поменять `ExecStart`
на `%h/develop/obs-twitch-chat/tts/.venv/bin/python server.py` и добавить
`Environment=TTS_ENGINE=piper`.

Бэкапы: `chat.html.pre-tts.bak`, `chat.html.pre-webaudio.bak` в папке виджета,
`Стрим.json.pre-tts.bak` — коллекция сцен до добавления источника (класть при закрытом
OBS, см. [[obs_music]]).
